# Short checklist

Tick a box only after the step is done.

## Before any probe

- [ ] The symptom is one sentence
- [ ] The local listener list was read
- [ ] The resolver file was read

### 中文

- [ ] 现象写成一句话
- [ ] 已经看过本机监听列表
- [ ] 已经看过解析器文件

## Stop

- [ ] If ping was used, it was recorded only as an ICMP result
- [ ] If the service should be local, the listener list shows that port or shows that it is absent

### 中文

- [ ] 如果用了 ping，只把它记成 ICMP 结果
- [ ] 如果服务应该在本机，监听列表里能看到该端口，或者能看到它不在
